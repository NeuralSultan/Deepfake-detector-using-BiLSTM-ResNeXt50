# Test Videos

This folder contains four sample videos used to test the Deepfake Detection System.

## Dataset Structure

```text
test_videos/
├── fake/
│   ├── FAKE1.mp4
│   └── FAKE2.mp4
│
└── real/
    ├── REAL1.mp4
    └── REAL2.mp4
```

## Contents

* **2 Real Videos** — authentic videos used to evaluate the model on genuine media.
* **2 Fake Videos** — manipulated/deepfake videos used to evaluate the model's ability to detect synthetic media.

## Purpose

These videos are provided as sample test cases for the deployed Streamlit application. They can be uploaded individually to verify the model's predictions and demonstrate the system's behavior on both real and manipulated videos.

> These videos are provided for demonstration and testing purposes only and are not part of the training dataset.
